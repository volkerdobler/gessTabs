# GESStabs 1.0.0

## Neuerungen in Version 1.0.0

Seit Version 0.2.9 ist einiges dazugekommen. Hier die wichtigsten Neuerungen im Überblick:

### Schneller navigieren

- **Gehe zu Definition**, **Alle Referenzen suchen** und **Umbenennen** (`F2`) funktionieren jetzt zuverlässig über mehrere per `INCLUDE` verbundene Dateien hinweg.
- Neuer Befehl **Gehe zu passendem Gegenstück** (`Ctrl+Shift+\`) springt auf einer `#MACRO`/`#ENDMACRO`-, `#IFDEF`/`#END`- oder ähnlichen Zeile direkt zum passenden Gegenstück.

### Hilfreiche Hover-Infos

- Beim Zeigen auf eine **Variable** erscheinen ihre Definition sowie `VARTEXT`, `VARTITLE` und `VALUELABELS`.
- Beim Zeigen auf einen **Makro-Aufruf** erscheinen dessen Definition und die aufgelöste Ersetzung.
- Beim Zeigen auf ein **Schlüsselwort** erscheinen Syntax und Beschreibung (rund 700 Schlüsselwörter, auf Deutsch oder Englisch, je nach Spracheinstellung).
- Beim Zeigen auf `TABLE`/`OVERVIEW`/`XOVERVIEW` erscheinen die an dieser Stelle tatsächlich wirksamen `CELLELEMENTS`/`FRAMEELEMENTS`-Voreinstellungen.

### Automatische Vervollständigung

- Vorschläge für Schlüsselwörter, bereits definierte Variablen-/Tabellennamen und Makros während des Tippens — inklusive Makroaufrufen direkt nach `#`.

### Mehr Warnungen, weniger Fehlalarme

Im Problems-Panel werden jetzt viele bekannte Stolperfallen automatisch erkannt, unter anderem:

- leere Variablenlisten bei `RECODE`/`VARTITLE`/`VARTEXT`/`VALUELABELS` (inklusive Schnellkorrektur),
- unvollständige `#MACRO`/`#IFDEF`-Blöcke,
- doppelte Variablendefinitionen,
- vertauschte `RECODE`-Grenzen,
- `WEIGHTCELLS`-Prozentwerte, die nicht 100 % ergeben,
- die veralteten `USEFILTER`/`MAKEFILTER` (durch `FILTER`/`TABLEFILTER`/`SETFILTER` ersetzt),
- Groß-/Kleinschreibungs-Konflikte zwischen `#define` und `#ifdef`.

Gleichzeitig wurden mehrere frühere Fehlalarme behoben (z. B. bei `IF v1 IS MULTIQ THEN …` oder bei Familien-Mitgliedern wie `medsort$1`).

### Angenehmer arbeiten

- Codefaltung für `#MACRO`/`#ENDMACRO`- und `#IFDEF`-Blöcke.
- Ein einfacher Formatierer (Leerzeichen, Leerzeilen, Einrückung).
- Eine erweiterte Sammlung an Textbausteinen (Snippets).
- Farbliche Unterscheidung von Variablen- und Makronamen gegenüber Schlüsselwörtern.
- Viele neue Einstellungen, um einzelne Funktionen (Hover, Diagnosen, Autovervollständigung) nach Wunsch ein- oder auszuschalten — siehe die README.

### Einstellungen und ihre Standardwerte

Alle Funktionen lassen sich einzeln über `Datei > Einstellungen` (Suche nach „gesstabs") anpassen:

- `gesstabs.autocomplete.enabled` (Standard: `true`) — Vorschläge für Schlüsselwörter, Makros und bereits definierte Variablen-/Tabellennamen während des Tippens.
- `gesstabs.hover.enabled` (Standard: `true`) — Hauptschalter für alle Hover-Infos.
- `gesstabs.hover.show` (Standard: alle Hover-Arten an, Makro-Anzeige `"short"`) — steuert einzeln, ob Hover für Schlüsselwörter, Variablen und Table-Defaults erscheinen, sowie ob der Makro-Hover die gekürzte (`"short"`) oder vollständige (`"full"`) Ersetzung zeigt.
- `gesstabs.hover.variableContent` (Standard: alle vier Blöcke an) — welche Blöcke der Variablen-Hover zeigt: Definition, `VARTEXT`, `VARTITLE`, `VALUELABELS`.
- `gesstabs.hover.language` (Standard: `"auto"`) — Sprache der Schlüsselwort-Beschreibungen; `"auto"` folgt der VS-Code-Anzeigesprache, `"de"`/`"en"` erzwingen eine Sprache.
- `gesstabs.diagnostics.enabled` (Standard: `true`) — Hauptschalter für alle Warnungen im Problems-Panel.
- `gesstabs.releaseNotes.showOnUpdate` (Standard: `true`) — automatisches Öffnen dieses Fensters bei einer neuen Version.
- `gesstabs.dataInput.entryScriptPatterns` (Standard: `main.tab`, `main*.tab`, `*.tab`) — welche `.tab`-Dateien als Einstiegsskripte gelten, aus denen die Rohdaten-Variablennamen gelesen werden.
- `gesstabs.logLevel` (Standard: nicht gesetzt, folgt `debugMode`) — Detailgrad der Logausgabe im „GESStabs"-Output-Kanal (`off`/`error`/`warn`/`info`/`debug`).
- `gesstabs.debugMode` (Standard: `false`, veraltet) — durch `gesstabs.logLevel` ersetzt.

### Dieses Release-Notes-Fenster

Das ist ebenfalls neu: Nach einem größeren Update öffnet sich künftig automatisch ein Fenster wie dieses mit den Neuerungen der jeweiligen Version. Die Checkbox unten ist standardmäßig angehakt, das heißt: Dieses Fenster erscheint für Version 1.0.0 nur dieses eine Mal. Wollen Sie es bei jedem Start erneut sehen, entfernen Sie einfach den Haken. Über den Befehl **GESStabs: Show Release Notes** (Command Palette) lässt es sich jederzeit erneut öffnen.

**Probleme oder Fehler gefunden?** Bitte melden Sie diese als Issue auf der [GitHub-Seite von GESStabs](https://github.com/volkerdobler/gessTabs/issues) — das hilft uns, die Extension weiter zu verbessern.

## What's New in Version 1.0.0

A lot has changed since version 0.2.9. Here are the highlights:

### Faster navigation

- **Go to Definition**, **Find All References**, and **Rename Symbol** (`F2`) now work reliably across files connected via `INCLUDE`.
- New **Go to Matching Directive** command (`Ctrl+Shift+\`) jumps straight to the matching counterpart on a `#MACRO`/`#ENDMACRO`, `#IFDEF`/`#END`, or similar line.

### Helpful hover information

- Hovering a **variable** shows its definition along with `VARTEXT`, `VARTITLE`, and `VALUELABELS`.
- Hovering a **macro call** shows its definition and the resolved expansion.
- Hovering a **keyword** shows its syntax and description (around 700 keywords, in German or English depending on your language setting).
- Hovering `TABLE`/`OVERVIEW`/`XOVERVIEW` shows the `CELLELEMENTS`/`FRAMEELEMENTS` defaults actually in effect at that point.

### Autocomplete

- Suggestions for keywords, already-defined variable/table names, and macros while you type — including macro calls right after typing `#`.

### More warnings, fewer false alarms

The Problems panel now automatically flags a number of known pitfalls, including:

- empty variable lists on `RECODE`/`VARTITLE`/`VARTEXT`/`VALUELABELS` (with a quick fix),
- incomplete `#MACRO`/`#IFDEF` blocks,
- duplicate variable declarations,
- swapped `RECODE` bounds,
- `WEIGHTCELLS` percentages that don't add up to 100%,
- the retired `USEFILTER`/`MAKEFILTER` (replaced by `FILTER`/`TABLEFILTER`/`SETFILTER`),
- case mismatches between `#define` and `#ifdef`.

At the same time, several earlier false alarms were fixed (e.g. on `IF v1 IS MULTIQ THEN …` or family members like `medsort$1`).

### A nicer editing experience

- Code folding for `#MACRO`/`#ENDMACRO` and `#IFDEF` blocks.
- A basic formatter (whitespace, blank lines, indentation).
- An expanded collection of code snippets.
- Variable and macro names are now visually distinguished from keywords.
- Many new settings to turn individual features (hover, diagnostics, autocomplete) on or off — see the README.

### Settings and Their Default Values

Every feature can be tuned individually via `File > Preferences > Settings` (search for "gesstabs"):

- `gesstabs.autocomplete.enabled` (default: `true`) — suggestions for keywords, macros, and already-defined variable/table names while typing.
- `gesstabs.hover.enabled` (default: `true`) — master switch for all hovers.
- `gesstabs.hover.show` (default: all hover types on, macro display `"short"`) — individually controls whether keyword, variable, and table-defaults hovers appear, and whether the macro hover shows the trimmed (`"short"`) or full (`"full"`) expansion.
- `gesstabs.hover.variableContent` (default: all four blocks on) — which blocks the variable hover shows: definition, `VARTEXT`, `VARTITLE`, `VALUELABELS`.
- `gesstabs.hover.language` (default: `"auto"`) — language of the keyword descriptions; `"auto"` follows VS Code's own display language, `"de"`/`"en"` force one.
- `gesstabs.diagnostics.enabled` (default: `true`) — master switch for all warnings in the Problems panel.
- `gesstabs.releaseNotes.showOnUpdate` (default: `true`) — automatically opens this window on a new version.
- `gesstabs.dataInput.entryScriptPatterns` (default: `main.tab`, `main*.tab`, `*.tab`) — which `.tab` files count as entry scripts to read raw dataset variable names from.
- `gesstabs.logLevel` (default: unset, follows `debugMode`) — verbosity of the "GESStabs" output channel log (`off`/`error`/`warn`/`info`/`debug`).
- `gesstabs.debugMode` (default: `false`, deprecated) — replaced by `gesstabs.logLevel`.

## P2 — Medium: cleanup & coverage gaps

- [x] **Fix the ~1634 findings `npm run lint` now surfaces** ✅ Done (2026-08-26). The CRLF/LF clash turned out to be purely local: the git objects were already LF, only Windows checkouts with `core.autocrlf=true` rendered them as CRLF on disk. Added `.gitattributes` (`* text=auto eol=lf`) to pin line endings repo-wide regardless of a contributor's local git config, renormalized the working tree, then ran `eslint --fix` (1819 → 93 findings). The remaining 93 were real rule violations, resolved via a mix of targeted `.eslintrc.json` additions (an `import/resolver`/`import/core-modules` override for `'vscode'` and relative `.ts` imports; `no-continue`/`no-plusplus` disabled globally — this codebase does character-by-character parsing with classic loops throughout `scope.ts`/`extension.ts`, rewriting all of them was judged higher-risk than worthwhile; `class-methods-use-this` off and `max-classes-per-file` raised to 4 for `extension.ts`'s four VS Code provider classes; `@typescript-eslint/no-unused-expressions` off for `test/**` since chai's `expect(...).to.be.true` style trips it) and direct code fixes (param-reassignment, nested ternary, a real variable-shadowing bug where `provideDocumentSymbols`'s local `spush` shadowed the module-level one used by `provideWorkspaceSymbols`, a missing `switch` default case, an unnecessary regex escape, `fsutils.ts`'s directory scan parallelized with `Promise.all` instead of a sequential `for` loop). Also fixed a real bug found along the way: `GesstabsReferenceProvider.provideReferences` had a disabled/dead code path whose early `return` inside the `Promise` executor never called `resolve()`, so "Find All References" would hang forever — now it resolves `null` immediately (still disabled pending a rewrite, but no longer hangs). `npm run lint` now reports 0 errors, 1 intentional warning (a `console.log` gated behind `gesstabs.debugMode`). `npm test` (18/18) and `npm run compile` reverified green throughout.

Documented as tested behavior rather than "fixed", since changing it would be a behavior change outside this pass's scope.
